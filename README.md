# Objetivo
Desenvolvi um site para um pet shop utilizando as tecnologias fundamentais da web, com foco em proporcionar uma experiência agradável e acessível aos usuários. As principais características do projeto incluem:

# Tecnologias utilizadas

* Html
* Css
* Bootstrap
  
# Metodologia

* Estruturação e Conteúdo:
Utilizei HTML para criar seções bem definidas, como serviços, produtos e contato, garantindo uma navegação intuitiva e conteúdo organizado.

* Estilização e Design Responsivo:
Apliquei CSS juntamente com o framework Bootstrap para estilizar o site, assegurando que o design seja atraente e adaptável a diferentes dispositivos e tamanhos de tela.

* Funcionalidades Interativas:
Implementei um menu adaptável que facilita a navegação, além de um carrossel interativo que destaca 
produtos e serviços, enriquecendo a experiência do usuário.
